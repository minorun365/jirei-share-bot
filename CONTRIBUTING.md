# Contributing

Thank you for improving Jirei Share Bot.

## Before opening a pull request

1. Create an issue for changes that affect the architecture, data model, Slack scopes, or AWS permissions.
2. Use synthetic data in code, tests, screenshots, and logs.
3. Run the TypeScript and Python tests, dependency audits, CDK synthesis, and `npm run check:public` as described in the README.
4. Explain the user-visible behavior and the tests you added.
